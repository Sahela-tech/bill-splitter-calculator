# 💸 Smart Bill Splitter Calculator

A modern, responsive web application built with clean MVC (Model-View-Controller) architecture to split group bills, calculate tips, and support multiple currencies in real time.

---

## 📌 Project Overview

The **Smart Bill Splitter Calculator** helps groups effortlessly divide restaurant bills or shared expenses. Built using vanilla JavaScript and structured cleanly with MVC principles, it requires no external libraries or heavy frameworks.

---

## 🔥 Features

- 🌍 **Multi-Currency Support:** Switch between **LKR (Rs.), USD ($), EUR (€), GBP (£), and INR (₹)**.
- 💡 **Flexible Tip Options:** Quick presets (**0%, 5%, 10%, 15%**) or custom tip inputs.
- 👥 **Equal Person Split:** Divide the total bill equally across any number of people.
- ⚡ **Real-Time Calculation:** Live breakdown updates automatically as you type.
- 📱 **Responsive Design:** Styled using modern CSS gradients and flex layouts for mobile, tablet, and desktop viewports.
