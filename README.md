# 💸 Smart Bill Splitter Calculator

> A sleek, responsive, and lightweight web utility to split group bills, calculate tips, and support multiple currencies in real time.

---

## 📌 Overview

**Smart Bill Splitter Calculator** helps you easily divide restaurant bills, group expenses, or event costs among friends. Built using vanilla web technologies without any heavy frameworks, it is fast, intuitive, and works seamlessly across all devices.

---

## 🔥 Key Features

| Feature | Description |
| :--- | :--- |
| 🌍 **Multi-Currency Support** | Switch effortlessly between **LKR (Rs.), USD ($), EUR (€), GBP (£), and INR (₹)**. |
| 💡 **Flexible Tip Options** | Quick presets (**0%, 5%, 10%, 15%**) or type any **Custom Tip %**. |
| 👥 **Dynamic Split** | Divide the final bill equally across any number of participants. |
| ⚡ **Instant Live Breakdown** | Get instant updates for **Tip Amount**, **Total Bill**, and **Share Per Person** as you type. |
| 📱 **Responsive UI** | Beautiful modern gradient design optimized for mobile, tablet, and desktop viewports. |

---

## 🛠️ Built With

- **HTML5** – Structured semantic elements
- **CSS3** – Modern styles using Flexbox, CSS Grid & Google Fonts (`Poppins`)
- **JavaScript (ES6+)** – Lightweight DOM manipulation and calculations

## 🚀 Getting Started

### Prerequisites

No special setup or node modules required! You only need a modern web browser (Chrome, Firefox, Edge, Safari).

1. **Clone or Download the Repository:**

2. **Navigate into the directory:**
```bash
cd bill-splitter-calculator
```
3. **Open the App:**
Double-click `index.html` to open it directly in your browser.
